# Task 057 — Убрать плашку ограничений и добавить показ спецсимволов

## Статус и владелец

- Статус: `Done`.
- Владелец: координатор; исполнитель: `cpp-developer`.

## Контекст

В continuous и paged WYSIWYG сверху постоянно показывалась плашка о
«limited WYSIWYG». Она занимает рабочую область и дублирует подсказки команд.
Пользователь также предложил не показывать пробелы/переводы строк по умолчанию
и добавить необязательный режим отображения спецсимволов.

## Цель

Убрать постоянную плашку; показывать ограничения только ситуативно; добавить
View → Show Special Characters, по умолчанию выключенный.

## Область работ

**Включено:** удаление banner-виджета, статусное сообщение о неточном cursor
mapping, toggle-действие, overlay пробелов/табов/концов абзацев в continuous и
paged canvas, тесты.

**Не включено:** отображение спецсимволов в Markdown source editor, сохранение
toggle в конфигурации, настройка внешнего вида маркеров пользователем.

## Ограничения и предположения

- Overlay является view-only и не меняет QTextDocument, source, token и undo.
- По умолчанию спецсимволы не показываются.
- Действие доступно только в WYSIWYG-режимах; новые окна начинают с off.
- Плашка не заменяется другим постоянным баннером; ошибки и приблизительный
  mapping сообщаются через status bar/диалоги.

## Критерии приёмки

1. В WYSIWYG больше нет постоянного `continuousNotice`/плашки.
2. Неточный cursor mapping показывается в status bar, а не в рабочей области.
3. Show Special Characters включает отображение пробелов точками, табов
   стрелками и концов абзацев `¶` в continuous и paged WYSIWYG; точка пробела
   центрируется в ячейке символа.
4. При выключенном режиме спецсимволы не видны; source/token не меняются.
5. Toggle синхронизирован между режимами и не влияет на Markdown editor.

## План проверок

- GUI tests: отсутствие плашки, status message, переключение action, различие
  отрисовки до/после, состояние canvas, отсутствие изменения source.
- Полный CTest Windows/Linux Debug.

## Зависимости и открытые вопросы

Task 054/056. Сохранение настройки между запусками не входит; при необходимости
оформить отдельно.

## Исполнительский промпт

Убери постоянную плашку, не теряя объяснение неточного mapping. Добавь
view-only overlay спецсимволов и View-toggle для обеих WYSIWYG-поверхностей.
Покрой тестами default-off, переключение и отсутствие мутации документа.

## Итог выполнения

- `ContinuousEditor` больше не создаёт `continuousNotice`; сообщение о
  приблизительном mapping эмитится сигналом и показывается в status bar.
- Добавлен `specialCharactersAction` (`Ctrl+Shift+8`), доступный в continuous и
  paged WYSIWYG.
- `PageTextEdit` и `PageCanvas` рисуют пробелы центрированными точками, табы
  стрелками и концы абзацев `¶` как overlay; документ не изменяется.
- Добавлен smoke test `continuousSpecialCharactersToggle`; тест mapping обновлён
  на status bar. Меню View обновлено.
- Проверки: Windows UCRT64 Debug — CTest 8/8; Ubuntu WSL GCC 15.2 Debug —
  CTest 7/7.
- Ограничение: режим не сохраняется между запусками; overlay предназначен для
  WYSIWYG, не для Markdown source.
