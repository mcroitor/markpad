# Task 055 — Сквозная приёмка страниц и PDF

## Статус и владелец

- Статус: `In Progress` (автоматическая приёмка пройдена; ждёт owner sign-off и ручные проверки).
- Контракт: [Task 051](task_051.md).

## Контекст

Unit tests не подтверждают видимые листы, реальную пагинацию PDF, системную IME
и поведение при overflow. Task 011 ждёт release QA.

## Цель

Подтвердить сквозную работоспособность и принять результат либо зафиксировать
блокеры.

## Область работ

**Включено:** матрица fixtures, фактическое сравнение canvas и PDF, визуальные и
кроссплатформенные проверки, итоговый review безопасности, системная IME,
документация и owner sign-off. Исправления возвращаются в 052–054/047.
**Не включено:** новая функциональность, изменение контракта 051, физическая
печать без доступного оборудования.

## Ограничения и предположения

- Parity и overflow — строго по 051; расчётный page count не считается
  фактическим содержимым PDF.
- Для документов с overflow PDF обязан отказать; это ожидаемое поведение, а не
  дефект parity.
- Не заявлять непроведённые проверки, owner sign-off или аудит выполненными.
- Accessibility full text interface не обещан; ограничение проверяется и
  документируется.

## Критерии приёмки

1. На fixtures без overflow фактический page count, размер страницы и порядок
   содержимого совпадают в canvas и PDF; tables/code/links/images сохранены.
2. Oversized-блок: canvas расширяет лист и показывает warning; PDF/печать
   отказывают с явной ошибкой, не повреждая файл.
3. Проверены правки, переключения режимов, undo/redo, copy/paste через страницы,
   системная IME (ручная), темы, DPI и безопасность недоверенного GFM/HTML.
4. Windows/Linux сборка и тесты, визуальные проверки и доступные DPI/IME
   сценарии зафиксированы; неподтверждённые пункты остаются открытыми.
5. Владелец принял результат; README, ARCHITECTURE и release checklist
   соответствуют фактическому поведению; Task 011 обновлена.

## План проверок

- Полный CTest и целевые GUI/PDF tests; PDF inspection и screenshots light/dark.
- Ручные IME/DPI/переключение режимов; фиксация недоступных проверок.
- Security review недоверенного Markdown/HTML и путей; diff review.

## Зависимости и открытые вопросы

047 Done, 054 Done; решение владельца и доступность обеих платформ. Физическая
печать — по фактической доступности оборудования.

Проверь 051, 052–054 и 047 независимыми fixtures. Не исправляй результаты
отчётом: дефекты верни соответствующей задаче. Обнови документацию и release
checklist, приложи команды, evidence, файлы, реальные результаты и риски.
Без owner sign-off или обязательной проверки не ставь Done.

## Итог выполнения

Автоматическая часть выполнена, приёмка **не завершена**:

- Fixture из 140 абзацев: paged canvas 5 страниц, PDF 5 страниц.
- Смешанный fixture (heading, bold/inline code, quote, list, fenced code, table,
  80 абзацев): page count canvas и PDF совпадает; PDF создаётся.
- Oversized-абзац: canvas `hasOverflow` и warning; PDF export отказывает и не
  создаёт файл.
- `pdfinfo`/`pdftotext` на projection PDF: A4 595x842, 5 страниц, извлекаемый
  текст присутствует.
- Windows UCRT64 Debug: 8/8 CTest (с opt-in pages spike). Ubuntu WSL GCC 15.2:
  7/7 CTest без opt-in spike; сборка и smoke проходят.

Не выполнено и не заявляется: owner visual sign-off, native visual QA,
системная OS IME, полный accessibility, физическая печать/CUPS, обновлённые
light/dark screenshots, полная матрица шрифтов/DPI/масштабов. Task 011 остаётся
открытой; Task 055 нельзя переводить в Done без этих проверок.
